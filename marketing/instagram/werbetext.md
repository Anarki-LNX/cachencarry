## Caption

Your network's package warehouse. 📦

Every Linux box in your homelab downloads the same updates. Again and again.
Cache & Carry keeps them on your own network: the first machine pulls a
package from the Internet, every other machine gets it at LAN speed.

✅ Pacman and APT: Arch, CachyOS, Debian, Ubuntu, Proxmox
✅ One download, shared live by every machine that asks for it
✅ Live dashboard with active downloads and clients
✅ Package signatures stay intact, no TLS interception
✅ One small binary, runs in a Proxmox LXC
✅ Free for everyone and open source (Apache 2.0)

⭐ Star it, try it, share it: github.com/Anarki-LNX/cachencarry (link in bio)

Built with Claude Code and Claude Fable 5.2.
