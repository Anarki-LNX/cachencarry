# Assets used

| Asset | Source | Notes |
|---|---|---|
| Interface footage (dashboard, downloads, clients, live traffic) | Recorded with Playwright from a local Cache & Carry 0.2.1 demo instance (`video/demo.sh`, `video/capture.mjs`) | Own software. Demo client addresses 10.0.10.x, no real network data |
| Package names and sizes on screen | Real Arch Linux and Debian packages fetched through the demo instance | Public package metadata |
| Logo mark | `assets/brand/mark-on-dark.svg` from this repository | Own design, generated by `scripts/build-brand.py` |
| Typeface | Adwaita Sans and Adwaita Mono, installed on the system | SIL Open Font License 1.1 |
| Music and sound effects | Synthesized with FFmpeg (`video/make-audio.sh`): sine tones, filtered pink noise | Own work, no samples from third parties |
| Text and subtitles | Written for this video | Own work |

Not used: stock video, stock music, AI image or video generators, paid
services, API keys.
