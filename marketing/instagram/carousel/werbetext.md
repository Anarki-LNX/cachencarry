## Caption

Every machine in your homelab downloads the same Linux updates. Here is how to stop that in a few minutes. 👇

Cache & Carry is a small, free cache for your network. The first machine pulls a package from the Internet, every other machine gets it from your own LAN.

🐧 Arch, CachyOS, Debian, Ubuntu and Proxmox
🔁 One download, shared live by every machine that asks
📊 Dashboard with active downloads and clients
🔏 Package signatures stay intact
🆓 Free and open source

💾 Save this post for your next homelab weekend.
⭐ Code and release: github.com/Anarki-LNX/cachencarry (link in bio)
