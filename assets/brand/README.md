# Cache & Carry brand files

Logo, icon and link preview image. All SVG files contain outlines only (no
fonts needed), so they look the same everywhere.

| File | Use |
|---|---|
| `icon.svg`, `icon-512.png`, `icon-192.png`, `icon-64.png`, `icon-32.png` | app icon and favicon (dark tile with the mark) |
| `mark-on-dark.svg`, `mark-on-light.svg` | the mark alone, transparent background |
| `logo-on-dark.svg` / `.png` | mark and name for dark backgrounds |
| `logo-on-light.svg` / `.png` | mark and name for light backgrounds |
| `logo-slogan-on-dark.svg` / `.png` | with the slogan, for dark backgrounds |
| `logo-slogan-on-light.svg` / `.png` | with the slogan, for light backgrounds |
| `social-card.svg` / `.png` | 1280 x 640 link preview and repository image |

**Name:** Cache & Carry (program and paths: `cachencarry`).

**Slogan:** Your network's package warehouse. Download once, carry out as
often as you like.

**Colours:** green `#34d399` (on light backgrounds `#059669`), ink `#0f1623`,
paper `#f8fafc`.

**The mark:** a trolley carrying a package with a download arrow. The name
plays on "cash and carry", the self-service wholesale warehouse.

The files are generated by `scripts/build-brand.py`. Change the script and
run it again instead of editing the files by hand. The lettering uses outlines
of Adwaita Sans (SIL Open Font License 1.1).
